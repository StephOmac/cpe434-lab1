# Scrum charter: [TEAM 15]

## Product Goal

Artisans (tailors, carpenters, electricians, painters and others) can build an online portfolio of the jobs they have completed, and the clients who hired them can verify and approve each job, so that new customers can trust the portfolio they see.

## Roles for Sprint 1 (rotate each Sprint)

- Product Owner: [Omachonu Stephen]. Speaks for artisans and their clients, and decides the order of the backlog.
- Scrum Master: [Ademuwagun Timilehin]. Keeps events on time and the board current, and chases blockers.
- Developers: [Omachonu Stephen, Ademuwagun Timilehin, Agbesola Moboluwaji, Adeniran Margaret, NNamdi Jordell]. Everyone builds, including the Product Owner and Scrum Master.

## Rhythm

- Sprint: 2 weeks
- Daily Scrum: [Friday, Saturday and Sunday by 3pm], 10 minutes, 3 times a week in person.
- Sprint Planning: about 30 minutes at the start of each Sprint
- Sprint Review: in the lab, where we show the Increment and gather feedback
- Retrospective: 15 minutes at the end of each Sprint

## Definition of Done

A card moves to Done only when all five are true:

- [ ] Compiles and runs on a teammate's machine
- [ ] Built on a branch and merged through a pull request
- [ ] At least one teammate reviewed and approved it
- [ ] Meets the card's acceptance check
- [ ] README says how to run it

## Kanban board

Board link: [[https://github.com/users/StephOmac/projects/1]]

- Columns: To do, In progress (max 3), In review, Done
- WIP limit: no more than 3 cards in In progress. Finish before starting something new.
- Pull, don't push: take the next card from To do only when a slot is free.
- Reviews come first: if In review is filling up, review a teammate's work before starting new work.

## Working agreements

- Every card has one name on it.
- Nobody pushes straight to `main`. Use a branch and a pull request.
- Reviews include at least one real comment, not just a click on Approve.
- If you are stuck for more than a day, say so in the group chat.
- Roles rotate every Sprint so everyone gets a turn.
